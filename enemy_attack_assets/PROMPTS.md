# ImageGen prompt set

Mode: built-in ImageGen, one call per monster. The attached input in every call
was the corresponding living runtime walk sheet from `reference/`.

## Shared prompt

> Use case: style-transfer. Asset type: production pixel-art game sprite sheet
> for PolyGrind. Create one attack animation sheet with exactly four sequential
> frames in one horizontal row, equal-size cells. Match the attached LIVING
> runtime reference: crisp limited-palette pixel art, hard pixel edges, no
> smoothing. Keep the same living monster fully visible in every frame, facing
> right, at consistent scale and bottom anchor, with no overlap. Preserve its
> identity, anatomy, palette, silhouette, equipment, and highlights. Pixels
> outside the character must be truly transparent. Never show a corpse, death,
> dying, collapse, prone/defeated pose, dismemberment, gore, extra character,
> detached projectile/VFX, floor, shadow, scenery, text, border, grid, UI, or
> watermark. This is a continuous attack, never a death sequence.

## Monster-specific briefs

- `runner`: compress → raise claw → forward claw/bite lunge → standing recoil.
- `blob`: brace shell → charge cyan core → short body-check → ready hover.
- `tank`: pull stone fist back → twist/raise → heavy forward punch → guard.
- `shooter`: points tighten → core charges → crystal discharge → core settles.
- `frostWolf`: crouch → push-off with jaws open → pounce/bite → controlled landing.
- `toxicRunner`: predatory wind-up → coil/raise claw → venomous claw-bite → recoil.
- `cursedRogue`: pull dagger back → step and twist → horizontal dagger cut → guard.
- `skeletonWarrior`: shield forward/sword back → raise sword → diagonal cut → shield guard.
- `blightGrunt`: pull club back → lift/twist → two-handed club smash → recover.
- `boneGargoyle`: crouch/fold wings → flare/drive → claw rake → fold/recover.
- `fallenPyromancer`: draw staff back → raise/brighten flame → thrust/release → lower staff.
- `beholderSlave`: converge stalks → compress/charge eyes → central-eye release → relax.
- `skeletonCrossbow`: aim/brace → tighten trigger → recoil on release → reset.
- `forgottenGuard`: brace behind tall spiked shield → launch crouch → shield-bash dash → upright guard.
- `abyssalExecutioner`: draw axe back → overhead raise → heavy diagonal chop → standing recovery.
- `plagueOgre`: pull fist back → lean/raise → supported ground-level punch → rise to ready stance.
