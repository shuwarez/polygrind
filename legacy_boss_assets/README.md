# Прежние боссы — исходники визуального обновления

Каталог хранит воспроизводимую цепочку обновления 14 боссов, которые были в
игре до новой двадцатки. Runtime остаётся автономным: игра читает только data URI
из `index.html`, а эти файлы нужны для аудита и повторной упаковки.

## Структура

- `reference/base/` — извлечённые прежние модели, использованные как визуальные
  референсы силуэта и палитры.
- `reference/effects/` — сохранённые удачные снаряды, разломы и длительные зоны.
- `generated/raw/` — оригинальные ImageGen-атласы 4×2: спокойное движение сверху,
  фирменная атака снизу.
- `generated/base_png/`, `generated/attack_png/` — очищенные и нормализованные
  листы 256×96, четыре кадра 64×96.
- `generated/effects_raw/`, `generated/effect_png/` — исходные и очищенные
  четырёхкадровые эффекты 384×96.
- `webp/base/`, `webp/attack/`, `webp/effects/` — окончательные lossless WebP,
  которые встраиваются в HTML.
- `*_contact.png` — контактные листы для визуального сравнения.

## Художественное задание ImageGen

Общий промпт для каждой модели: создать transparent-background pixel-art sprite
atlas 4 columns × 2 rows, сохранить дизайн и палитру приложенного референса;
верхний ряд — четыре последовательных кадра idle/crawl, нижний — четыре
последовательных кадра signature attack; одинаковый масштаб, нижняя привязка,
без текста, UI, рамок, теней от сцены и запечённого пола. Варианты фирменной
атаки: `lich` — заряд/выпуск изумрудной сферы; `goat` — удар в землю; `plague` —
плевок слизью; `greed` — создание/бросок золотого копья; `executioner` — бросок
топора; `tyrant` — огненный взмах мечом; `grave` — фиолетовый призыв; `behemoth`
— прыжок/приземление; `vampire` — кровавый рывок; `voidwrath` — открытие
разлома; `minotaur` — разгон/таран; `seraph` — святое копьё; `matriarch` —
рождение личинки; `demonqueen` — превращение в сгусток и обратная сборка.

Отдельные эффекты создавались промптом: transparent-background pixel-art VFX
sprite sheet, exactly four horizontal frames, 96×96 per frame, centered and
consistently scaled, no character/floor/UI/text. Темы: каменный радиальный удар,
тяжёлое приземление, дорожка тарана, огненный серп, кровавый крест и магическая
руна призыва.

## Сборка и установка

```powershell
python extract_legacy_boss_assets.py
python prepare_legacy_boss_assets.py
python embed_legacy_boss_assets.py
node legacybossartunit.js
node bossunit.js
```

`prepare_legacy_boss_assets.py` удаляет только связанный светлый фон, приводит
кадры к каноническим размерам и пишет lossless WebP. `embed_legacy_boss_assets.py`
проверяет HTML-якоря и обновляет три каталога data URI. Урон, коллизии, радиусы и
тайминги этими инструментами не меняются.

Текущий runtime-бюджет: 14 базовых листов — 178260 байт, 14 атакующих — 240090
байт, шесть эффектных — 208212 байт; всего 626562 байта до base64-встраивания.
