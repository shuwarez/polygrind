# Портал завершения этажа

`floor-portal-master.png` — прозрачный мастер, созданный встроенным ImageGen по
референсу прежнего портала. Runtime-лист воспроизводимо собирается и встраивается:

```powershell
python optimize_graphics.py --floor-portal portal_assets/floor-portal-master.png --install-floor-portal
```

Упаковщик проверяет SHA-256 мастера и создаёт 16 полноразмерных кадров `128×128`:
внешнее архитектурное кольцо остаётся неподвижным, а внутренний вихрь вращается и
мягко пульсирует. Runtime бесшовно зацикливает кадры с длительностью 80 мс.

Финальный prompt: новый детализированный dark-fantasy портал для top-down RPG;
готическое каменно-металлическое кольцо, руны, аметистовые кристаллы, вихрь
cyan/blue/violet, прозрачный фон, один объект без текста и окружения.
