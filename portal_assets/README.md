# Инфернальный портал завершения этажа

`infernal-portal-master.png` — прозрачный мастер жутких базальтово-железных врат,
созданный встроенным ImageGen. `floor-portal-master.png` оставлен как архив прежней
сине-фиолетовой версии. Два runtime-листа воспроизводимо собираются и встраиваются:

```powershell
python optimize_graphics.py --floor-portal portal_assets/infernal-portal-master.png --install-floor-portal
```

Упаковщик проверяет SHA-256 мастера и создаёт два листа по 16 полноразмерных кадров
`128×128`: рост врат из кровавой трещины и рабочий цикл. В цикле арка, кости,
цепи, шипы и baseline побитово стабильны; меняются только инфернальный огонь и
блики крови. Runtime проигрывает появление за 1,28 с, затем цикл по 90 мс.

- `infernal-portal-appear-16x128.png` — появление, `2048×128`, 16 кадров.
- `infernal-portal-loop-16x128.png` — бесшовный рабочий цикл, `2048×128`, 16 кадров.

Финальный prompt (встроенный ImageGen): один брутальный жуткий портал для top-down
dark-fantasy RPG; тяжёлые врата из чёрного железа, расколотого базальта, рёбер и
клыков; чёрно-красная инфернальная рана, цепи, кровь и угли; прозрачный фон,
стабильная симметричная конструкция и единая горизонтальная baseline; без текста,
рун, кристаллов, cyan/blue/violet и космической магии.
