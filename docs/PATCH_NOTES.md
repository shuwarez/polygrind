# Патчноут — переход на структурированный проект

Дата: 2 сентября 2026 года

## Главное изменение

Grim Grind окончательно переведён с монолитного HTML-файла на нормальную
многофайловую архитектуру. Это новый основной формат проекта и дальнейшей
разработки.

## Что изменилось

- `index.html` теперь содержит только небольшую разметку и порядок подключения.
- Игровая логика разделена на 17 файлов по подсистемам в `src/game/`.
- Интерфейс разделён на 7 таблиц стилей в `src/styles/`.
- Изображения, звуки и шрифты вынесены в тематические каталоги `assets/`.
- 524 используемых runtime-ресурса зафиксированы в `assets/manifest.json` с
  размерами и SHA-256.
- Добавлена автоматическая проверка отсутствующих и неиспользуемых ассетов.
- Тесты перенесены в `tests/` и больше не зависят от `art-source` или старых
  монолитных упаковщиков.
- Удалены исходные концепты, промежуточные рендеры, старые отчёты, ручные
  диагностические файлы и одноразовые миграционные инструменты.
- GitHub Pages теперь собирает и публикует `index.html`, `src/`, `assets/` и
  файл пользовательского домена `CNAME`.

## Для разработки

Основные команды:

```powershell
npm start
npm run check
npm run assets:manifest
```

`npm run check` проверяет архитектуру и запускает 2254 регрессионные проверки.
Любой новый ассет должен быть финальным runtime-файлом, иметь ссылку из JS/CSS
и присутствовать в автоматически созданном manifest.

## Совместимость

Игровые механики и ключи постоянного сохранения при структурной миграции не
менялись. Обновление изменяет организацию проекта, а не баланс или прогресс
игрока.
