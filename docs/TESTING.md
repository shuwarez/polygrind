# Проверка проекта

## Команды

Структура и ресурсы:

```powershell
npm run verify
```

Полная игровая регрессия:

```powershell
npm test
```

Обе проверки:

```powershell
npm run check
```

Для последовательной диагностики:

```powershell
$env:RUN_ALL_JOBS=1
npm test
```

Ожидаемый итог полного набора: `2254 · всё зелёное` и успешный `orderscan`.

## Профильные тесты

Во время разработки сначала запускайте ближайший набор:

```powershell
node tests/damagecontextunit.js
node tests/spriteunit.js
```

`tests/harness.js` читает внешние `<script src>` в порядке `index.html` и
исполняет их в одном VM-контексте. `loadInspectionSource()` объединяет текст и
runtime-ресурсы только в памяти тестового процесса; файл-сборка на диске не
создаётся.

Активный набор не зависит от `art-source` или старых упаковщиков. Графические
тесты проверяют непосредственно финальные файлы из `assets/`.

## Визуальная проверка

После изменений интерфейса, Canvas, шрифтов, изображений или звука запустите
локальный сервер. Проверьте главное меню, переход к выбору подкласса и игру, а
также отсутствие ошибок и 404 в Console/Network.
