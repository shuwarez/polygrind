# PolyGrind: 20 новых боссов

Источник концептов и базовых четырёхкадровых спрайтшитов:

`C:/Users/User/Documents/ChatGPT/PolyGrind/deliverables/boss_concepts_20/PolyGrind_20_New_Bosses_Simplified_Percent_HP_Attacks_RU.docx`

## Структура

- `previews/` — исходные иллюстрации из DOCX для визуальной сверки.
- `sheets/` — восстановленные RGBA PNG, 256×96, четыре кадра по 64×96.
- `webp/` — финальные lossless WebP базовых анимаций, встроенные в `PolyGrind.html`.
- `generated_attack/source/` — сгенерированные дополнительные анимации атак.
- `generated_attack/webp/` — нормализованные lossless WebP дополнительных анимаций.
- `boss20_contact_sheet.png` и `generated_attack/attack_contact_sheet.png` — контактные листы для QA.

## Дополнительные анимации

По базовым спрайтам были созданы четыре отдельные четырёхкадровые анимации:

1. Похоронный Колокол — раскрытие корпуса и удар колокола.
2. Пожиратель Звёзд — раскрытие и схлопывание грудной пасти.
3. Мать Пустых Масок — последовательный разворот масок.
4. Хранитель Последней Свечи — затухание и вспышка свечи.

Общий промпт: сохранить силуэт, палитру, пиксельный масштаб и нижнюю точку привязки исходного босса; показать ровно четыре последовательные фазы описанной спецатаки; не добавлять текст, интерфейс, окружение или тень; прозрачный фон.

## Воспроизведение
