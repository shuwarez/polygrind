# Grim Grind

Чистая структурная рабочая копия браузерной игры. В каталоге находятся только
runtime, активные тесты, инструменты разработки, документация и публикация.
Исходные концепты, промежуточные рендеры, миграционные скрипты, старые отчёты и
резервные копии в проект не входят.

## Быстрый старт

Требуется Node.js 18 или новее. Сторонние npm-пакеты не нужны.

```powershell
npm start
```

Откройте `http://127.0.0.1:4173`.

Полная проверка проекта:

```powershell
npm run check
```

Команда проверяет структуру, комплектность ассетов и всю игровую регрессию.

## Состав проекта

| Путь | Для чего нужен |
| --- | --- |
| `index.html` | Небольшая разметка и порядок подключения CSS/JS. |
| `src/game/` | Игровая логика по подсистемам. |
| `src/styles/` | Стили меню, HUD и игровых панелей. |
| `assets/` | Все и только используемые изображения, звуки и шрифты. |
| `tests/` | Наборы, которые запускает `run-all.js`, и их общие helpers. |
| `tools/dev-server.js` | Локальный статический сервер. |
| `tools/update-asset-manifest.js` | Пересборка manifest по ссылкам из runtime. |
| `tools/verify-structure.js` | Проверка структуры и отсутствия лишних ассетов. |
| `docs/` | Архитектура, разработка, ассеты и тестирование. |
| `.github/workflows/deploy.yml` | Проверка и публикация GitHub Pages. |

Папок `art-source`, `old versions`, `tools/migration` и
`tools/legacy-monolith` здесь намеренно нет. Они не требуются ни игре, ни
активным тестам, ни публикации.

## Рабочие команды

```powershell
npm start                 # локальная игра
npm run verify            # структура и комплектность
npm test                  # вся регрессия
npm run assets:manifest   # обновить manifest после изменения ассетов
npm run check             # verify + test
```

## Правила чистого проекта

- Не помещать JavaScript, CSS или бинарные data URI внутрь `index.html`.
- Класть в `assets/` только финальный файл, на который ссылается runtime.
- Не хранить рядом концепты, исходные PSD/PNG, contact sheets и временные
  экспорты. Для них используется отдельное внешнее хранилище.
- После добавления, замены или удаления ресурса выполнять
  `npm run assets:manifest`, затем `npm run check`.
- Новый JS/CSS-файл подключать в `index.html` в правильном порядке.
- Новый пользовательский текст одновременно добавлять на русском и английском.

Подробнее: [архитектура](docs/ARCHITECTURE.md),
[разработка](docs/DEVELOPMENT.md), [ассеты](docs/ASSETS.md) и

## Публикация

GitHub Actions проверяет проект и публикует только `index.html`, `src/` и
`assets/`. Никакой монолитный HTML или промежуточный build-файл в репозитории
не создаётся.
