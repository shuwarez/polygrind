# PolyGrind — handover

## Быстрый запуск

Игра запускается без сборки: откройте `PolyGrind.html` в актуальном Chrome, Edge или Firefox. Это статическая одностраничная Canvas-игра; сервер и npm-зависимости не требуются.

Для публикации на GitHub Pages в репозитории есть workflow `.github/workflows/deploy.yml`. Он копирует статические файлы проекта в Pages-артефакт.

## Структура

| Путь | Назначение |
| --- | --- |
| `PolyGrind.html` | Весь исходный код игры: HTML, CSS, JavaScript, баланс и встроенные графические данные. |
| `.github/workflows/deploy.yml` | Автоматическая публикация статического билда на GitHub Pages. |
| `old versions/` | Резервные снимки `PolyGrind.html` перед заметными правками. В каждой папке есть `README.txt` с датой и причиной сохранения. |

Спрайты персонажей встроены прямо в HTML в виде данных, поэтому отдельная папка `assets` не требуется.

## Игровые системы

- Доступные классы: Лучник, Маг и Некромант; после выбора класса выбирается подкласс.
- Работают уровни, случайные карточки навыков, предметы, этажи, элитные противники и боссы.
- `Tab` открывает инвентарь и панель характеристик, одновременно ставя игру на паузу.
- После смерти открывается экран итогов забега; кнопка возвращает в главное меню.
- Магазин использует постоянное золото и улучшения, сохранённые между запусками.
- Контактный урон монстров применяется два раза в секунду.
- На новом этаже герой восстанавливает 10% максимального здоровья; пассивного прироста здоровья и урона за этаж нет.
- Подсказки карточек открываются при наведении и описывают механику, формулу и текущий эффект.

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` | Движение. |
| `Пробел` | Рывок. |
| `Tab` | Инвентарь / характеристики и пауза. |
| `P` или `Esc` | Пауза. |

### Служебный режим QA

Клавиша `L` во время забега открывает скрытую тестовую панель и ставит игру на паузу. В ней можно искать карточки и выдавать их персонажу; для карточек также доступны всплывающие подсказки. Эта клавиша намеренно не показана в игровом интерфейсе.

## Сохранения

Постоянный прогресс магазина хранится под ключом `grinder_meta_reset_2026`. В окружении Codex используется доступное облачное хранилище `window.storage`; при обычном запуске в браузере применяется `localStorage`.

Не меняйте этот ключ без миграции: это создаст игрокам новое сохранение магазина.

## Важные ограничения

- Основной исходный код намеренно находится в одном HTML-файле. При крупных изменениях удобно искать функции по `rg` и проверять синтаксис перед открытием в браузере.
- Папка `old versions/` со временем увеличивается. Она сохраняется в репозитории как история ручных снимков по требованию проекта.
- Баланс, каталог карточек, визуальный интерфейс и логика рендера тесно связаны внутри `PolyGrind.html`; перед большой переработкой обязательно создавайте новый снимок в `old versions/`.
