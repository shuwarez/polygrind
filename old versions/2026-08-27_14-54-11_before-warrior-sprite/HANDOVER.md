# PolyGrind — handover

## Быстрый запуск

Игра запускается без сборки: откройте `PolyGrind.html` в актуальном Chrome, Edge или Firefox. Это статическая одностраничная Canvas-игра; сервер и npm-зависимости не требуются.

Для публикации на GitHub Pages в репозитории есть workflow `.github/workflows/deploy.yml`. Он копирует статические файлы проекта в Pages-артефакт.

## Структура

| Путь | Назначение |
| --- | --- |
| `PolyGrind.html` | Весь исходный код игры: HTML, CSS, JavaScript, баланс и встроенные графические данные. |
| `.github/workflows/deploy.yml` | Автоматическая публикация статического билда на GitHub Pages. |
| `HANDOFF.md` | Подробная техническая передача: архитектура, баланс, инварианты и известные ограничения. |
| `HANDOVER.md` | Краткая инструкция по запуску, структуре, сохранениям и публикации. |
| `harness.js`, `*unit.js`, `run-all.js` и служебные `.js` | Полный Node-харнесс: 19 наборов, 295 проверок, симуляции и диагностические замеры. |
| `BALANCE_REPORT.md` | Методика и результаты отдельного детерминированного аудита четырёх классов. |
| `old versions/` | Резервные снимки `PolyGrind.html` перед заметными правками. В каждой папке есть `README.txt` с датой и причиной сохранения. |

Спрайты персонажей встроены прямо в HTML в виде данных, поэтому отдельная папка `assets` не требуется.

## Игровые системы

- Интерфейс и весь игровой контент доступны на английском и русском. Английский выбран по умолчанию; в главном меню есть флажки EN/RU, а выбор сохраняется между запусками.
- Доступные классы: Лучник, Маг и Некромант; после выбора класса выбирается подкласс.
- Клинок остаётся в данных и баланс-тестах, но пока скрыт из меню до появления подклассов. Каждый третий взмах Клинка — круговая волна с гарантированным отбрасыванием и коротким головокружением.
- Работают уровни, случайные карточки навыков, предметы, этажи, элитные противники и боссы.
- `Tab` открывает инвентарь и панель характеристик, одновременно ставя игру на паузу.
- После смерти открывается экран итогов забега; кнопка возвращает в главное меню.
- Магазин использует постоянное золото и улучшения, сохранённые между запусками.
- Регенерация в магазине стоит вдвое дороже прежнего и ограничена 50 HP/сек.
- В меню «Созвездия» навсегда учитываются убийства Бегунов, Ядер, Бастионов, Призм, элиты и боссов. Десять вручную открываемых рангов каждого созвездия дают до +50% к урону, опыту и золоту против соответствующего типа.
- Тотем соответствующей стихии начинает выпадать только после получения хотя бы одной книги этой стихии.
- На этажах, кратных пяти, боссы чередуются по количеству `1 → 2`, а число аффиксов растёт каждые два таких этажа. С 80-го этажа постоянно появляются два босса со всеми восемью аффиксами.
- Отталкивание слабее действует на Бегунов, элиту и боссов; рывок проходит около 240 единиц и восстанавливает заряд за 5 секунд.
- Подкласс Вор сохраняет +1% скорости передвижения за уровень и получает отдельный множитель +2% ко всему золоту за уровень вместо уклонения.
- Вся свита Некроманта наносит на 50% меньше урона, имеет на 75% меньшие шансы стихийных эффектов и естественно умирает через случайные 10–15 секунд с обычным возрождением через 0.25 секунды.
- Кейстоун Некроманта «Лорд Смерти» лечит героя на 0.1% фактически нанесённого свитой урона. Старая синяя карточка лечения свитой удалена, а «Ужасающий вампир» для Некроманта отключён.
- Контактный урон монстров применяется два раза в секунду.
- На новом этаже герой восстанавливает 10% максимального здоровья; пассивного прироста здоровья и урона за этаж нет.
- Подсказки карточек открываются при наведении и описывают механику, формулу и текущий эффект.

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` | Движение. |
| `Пробел` | Рывок. |
| `Tab` | Инвентарь / характеристики и пауза. |
| `P` или `Esc` | Пауза. |

### Служебный режим QA

Клавиша `L` во время забега открывает скрытую тестовую панель и ставит игру на паузу. В ней можно искать карточки и выдавать их персонажу; для карточек также доступны всплывающие подсказки. Эта клавиша намеренно не показана в игровом интерфейсе.

## Сохранения

Выбранный язык хранится отдельно под ключом `polygrind_language`; не объединяйте его с мета-прогрессией.

Постоянный прогресс магазина и созвездий хранится под ключом `grinder_meta_reset_2026`. В окружении Codex используется доступное облачное хранилище `window.storage`; при обычном запуске в браузере применяется `localStorage`. Старые сохранения мягко получают нулевые счётчики созвездий без сброса золота и магазина.

Не меняйте этот ключ без миграции: это создаст игрокам новое сохранение магазина.

## Проверки перед публикацией

Полная регрессия запускается одной командой и должна завершиться результатом
`всего проверок: 295 · всё зелёное`:

```powershell
$env:Path = 'C:\Users\alivp\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin;' + $env:Path
node run-all.js
```

Проверка синтаксиса встроенного JavaScript:

```powershell
& 'C:\Users\alivp\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' -e "const fs=require('fs');const h=fs.readFileSync('PolyGrind.html','utf8');const s=[...h.matchAll(/<script[^>]*>([\s\S]*?)<\/script>/gi)].map(x=>x[1]);s.forEach(x=>new Function(x));console.log('Syntax OK: '+s.length+' script block(s)');"
```

Последняя нагрузочная проверка некроманта: 55-й этаж, 250 одновременно поддерживаемых врагов, 34 миньона и 53 секунды симуляции. Ошибок JavaScript и аварийного завершения не выявлено.

## Важные ограничения

- Любой новый видимый текст добавляется сразу на английском и русском; `node locunit.js` проверяет полноту пар каталогов.
- Основной исходный код намеренно находится в одном HTML-файле. При крупных изменениях удобно искать функции по `rg` и проверять синтаксис перед открытием в браузере.
- Папка `old versions/` со временем увеличивается. Она сохраняется в репозитории как история ручных снимков по требованию проекта.
- Баланс, каталог карточек, визуальный интерфейс и логика рендера тесно связаны внутри `PolyGrind.html`; перед большой переработкой обязательно создавайте новый снимок в `old versions/`.
